```
PoolPilot is an open-source, non-custodial Automated Market Maker (AMM) prototype implementing the constant-product invariant (x · y = k) for transparent, trustless ERC-20 token swaps on EVM-compatible networks.

Key features:
• Exact constant-product pricing with integer-safe math (no rounding exploits)
• 30 basis point (0.30%) fee per swap, compounded directly into LP reserves
• First-depositor share inflation defense via permanent dead-address LP lock
• Proportional liquidity provision and redemption (ERC-20 PLP shares)
• Slippage protection with automatic hard revert on threshold breach
• React 18 + Vite frontend with real-time reserve indexing and glassmorphism design system
• 35 automated tests: 21 smart contract invariant/unit tests + 14 frontend unit tests

Tech Stack: Solidity 0.8.24, OpenZeppelin v5 (SafeERC20, ERC20, ReentrancyGuard, Math), Hardhat, Foundry, React 18, Vite, Ethers.js

Status: Functional prototype deployed on local testnet with full deployment scripts for Sepolia/Holesky.
```
